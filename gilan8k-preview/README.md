# GILAN 8K Online Preview

This is a separate preview folder, added without changing the existing root website in this repository.

- Three sections only: Live, Movies, Series.
- Admin-only demo playlist management.
- Demo device records with MAC and activation code.
- Local browser storage only; not a production backend.
- No channels or streams are bundled.

This preview is intended for UI iteration on Android Chrome. A real backend, secure activation, licensed playlist import, and Samsung Tizen WGT build are separate production steps.
